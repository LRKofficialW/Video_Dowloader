# ВидеоЗагрузка

Локальное веб-приложение для скачивания видео и аудио через yt-dlp и простого редактирования видео через FFmpeg.

## Запуск в Windows

1. Установите Python 3.10+.
2. Дважды щёлкните `start.bat`. Скрипт установит зависимости и откроет приложение на `http://127.0.0.1:5000`.
3. Для редактирования видео установите FFmpeg и добавьте его в PATH. Скачивание видео обычно требует FFmpeg для склейки звука и изображения. Извлечение MP3 и WAV также использует FFmpeg.

Вставьте ссылку на видео, выберите видео или аудио, качество/формат и нажмите «Скачать». Для обрезки, изменения скорости и отключения звука переключитесь на «Редактировать видео». Результаты сохраняются в папке `downloads`.

Скачивайте только материалы, которые разрешено сохранять. Возможности зависят от сайта и его ограничений.
